## VIP 到期时间显示成 1970-01-01T00:00:00.000Z

### 根因
非会员时上游给的是 0 / "0"，`api/youth.ts` 的 `extractExpireAt` 把数字直接
`new Date(value * 1000).toISOString()`，0 就变成 1970-01-01T00:00:00.000Z；
`api/user.ts` 的 `vip_end_time` 同样会把 "0" 当有效字符串返回。

### 改动
- `utils/format.ts` 新增 `formatDateTime(value)`：兼容秒/毫秒时间戳、`YYYY-MM-DD`、
  `YYYY-MM-DD HH:mm:ss`、ISO 串；`<= 0`、`"0"`、空值、年份 < 1971 一律返回 null；
  输出 `YYYY-MM-DD`，带时分且非 00:00 时输出 `YYYY-MM-DD HH:mm`。
- `api/youth.ts`：`extractExpireAt` 跳过 0 与 `"0"`。
- `api/user.ts`：新增 `pickDateString`，`vip_end_time` 为 `"0"` 时返回 null。
- `Profile.vue`：`vipExpire` 改为 `formatDateTime(...)`，无效值返回 null → 整行不渲染。

### 坑
`new Date('2026-10-22')` 按 UTC 零点解析，东八区取本地时分变成 08:00，
所以纯日期必须手动按年月日构造本地 Date（已在 formatDateTime 里单独分支处理）。

### 验证
运行时用 dev server 动态 import 该模块跑了 13 个用例：
1970 ISO / 0 / "0" / "" / null / "not-a-date" / 86400 → null；
"2026-10-22" → 2026-10-22；"2026-10-22 12:00:00" → 2026-10-22 12:00；
"2026-10-21T16:00:00.000Z" → 2026-10-22（东八区换算正确）；时间戳秒/毫秒均正确。
`npm run typecheck` 通过。

  新增 `actualQuality` / `degraded` / `qualityTitle`：降级时 tooltip 写明「当前实际 X，无权限时自动降级」，
  菜单里在**实际**音质那一项标「实际」（原来标「当前」且用的是 `streamQuality ?? quality`）。
- `player.ts`：`clear()` 时把 `streamQuality` 置 null，避免停止后 tooltip 还指向上一首的降级结果。
- `App.vue`：补 `watch(() => player.quality, next => settings.quality = next)`。
  **播放栏切音质原来不写回设置**（模式有写回、音质没有），重启后会退回旧值。
- `Settings.vue`：音质说明改为「切换后立即生效，当前曲目会按新音质重新加载」，
  因为 `setQuality` 本来就会重载当前曲，原「下一首生效」是错的。

### 验证（Electron 实测）
- 未播放：胶囊「高清 320K」（默认偏好 320）。
- 未登录播放「晴天」：胶囊仍是「高清 320K 试听」，title 为
  「音质：高清 320K（当前实际 标准 128K，无权限时自动降级）」，菜单里 128 标「实际」、320 打勾。
- 播放栏切 FLAC → localStorage `settings.quality = "flac"`、胶囊「无损 FLAC」；切回 320 同样写回。

## 多歌手拆成独立链接

### 背景
`TrackTable` 把「汪苏泷、BY2」整串渲染成一个按钮，点击永远进第一个歌手（`artistId` 取 `strFirst`），
文字和目标对不上。实测：点「BY2」也跳到 `#/artist/1485`（汪苏泷）。

### 改动
- `types/kugou.ts`：新增 `TrackArtist { id?, name }`，`Track.artists?: TrackArtist[]`。
- `api/track.ts`：新增 `strList` / `splitSingerNames` / `artistsFrom` / `artistsOf`。
  - 优先结构化数组：`singerinfo`（歌单）→ `authors`（榜单）→ `Singers`。
  - 只有「拼接串 + id 数组」时（搜索的 `SingerName` + `SingerId`）按数量对齐才拆分；
    **对不上就整串当一个歌手 + 兜底 id** —— 宁可不跳，也不指错人。
  - `singer` / `artistId` 提到 return 之前先算，`artists` 复用它们。
- `TrackTable.vue`：歌手列改成 `v-for` 渲染多个 `.song__singer-link`，缺 id 的歌手渲染纯文本；
  新增 `goArtistId()`，删掉 `goArtist(track)`；分隔符用 ` / `（`.song__singer-sep`）。
  注意不能复用 `.link`（那是专辑列用的 block 满宽）。

### 实测
- 搜索「有点甜」：`links: ["汪苏泷","BY2"]`；点第二个 → `#/artist/83926`（BY2），点第一个 → `#/artist/1485`（汪苏泷）。
- 单歌手（禾月）仍是单个链接；歌单页曲目链接正常（`singerinfo` 分支）。
- 歌手页（`/artist/:id`）的曲目没有歌手 id，渲染为纯文本 —— 与改动前一致，不是回归。
