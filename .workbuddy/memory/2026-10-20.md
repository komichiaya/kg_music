## UI 选型评估：Element Plus vs 自研样式

仅调研与决策，**未改动任何代码**。结论：以自研为主，Element 收敛为按需库；用户选择暂不执行。

### 现状核查
- Element Plus 仅用于 `Settings.vue`：`el-select`×2（音质/播放模式）、`el-switch`×5。
- 无 `app.use(ElementPlus)`，靠 `unplugin-vue-components` + `ElementPlusResolver` 按需导入。
- 仅引入 `theme-chalk/dark/css-vars.css` 一行，无 `ElMessage` / `ElMessageBox` / `ElLoading`。

### 关键数据
- `dist/assets/Settings-*.css` = **34.0 KB**，含 56 个 `el-` 选择器；其他路由页 1.6–6.5 KB。
- 这两个组件实际引用 **56 个** `--el-*` 变量，`tokens.css` 只桥接 **14 个（25%）**。
- 未桥接高影响项：`--el-switch-off-color` / `--el-fill-color-light` /
  `--el-border-color-hover` / `--el-box-shadow-light`。
- `index-B-L2sHP_.css` 37 KB 中仅 3 个 `el-` 类，说明 dark css-vars 是纯变量、代价很小。

### 判断
- 设置页是唯一引入 Element 的页面，也是全项目最大单页 CSS —— 体积与收益严重失衡。
- 变量桥接只能覆盖主色，覆盖不了边缘状态（关闭态/悬停/阴影），这是设置页需要人工调校的根因。

## 修复 Rank 页榜单卡片被压扁

### 现象
排行榜左侧榜单卡片（`button.rank.panel`）只剩 ~22px 高的一条，封面/文字被 `.panel` 的
`overflow:hidden` 裁掉。

### 排查（Edge headless + dist 临时测量脚本，实测数据）
- 裸 `<button style="display:flex">` + 同内容 = 64px 正常 → **不是 button+flex 的锅**。
- 把真实卡片 clone 到 `.list` 外 = 66px 正常 → 问题在容器。
- 根因：`.list` 是 `flex-direction: column` + `max-height` + `overflow-y: auto`，
  子项默认 `flex-shrink: 1`，而卡片 `.panel` 的 `overflow:hidden` 使 flex item 的
  `min-height:auto` 保护失效 → 55 张卡被均分压进 max-height，每张 22px。
  单独给一张卡设 `flex:0 0 auto` 立即恢复 66px，坐实结论。

### 修复
`Rank.vue` 的 `.list` 增加 `.list > * { flex: none }`，溢出交给 overflow-y 滚动。
重建后截图验证卡片恢复 66px、列表可滚动。

### 排查方法论（可复用）
`npx vite build` → `python -m http.server` 托管 dist（file:// 打不开 ES module）→
往 dist/index.html 注入 `<script src="./measure.js">`（CSP 只允许 'self'，内联脚本会被拦）
用 getBoundingClientRect 输出 `MEASURE:` 文本节点 → `msedge --headless=new --dump-dom` grep。

## 修复：切歌回来保留进度（断点续播语义误用）

### 症状
A 曲听到一半 → 切 B → 切回 A，A 从上次中断处继续播放。

### 根因（`src/stores/player.ts`）
断点续播被当成了「会话内切歌」的机制：
1. `playAt()` 切歌前 `saveCurrentResume(true)` 强制落盘旧曲位置；
2. `loadCurrent()` 无条件 `pendingSeek = readResume(track.hash)`，只要落盘有值就续播。
于是同一次运行内的切换等价于一次「重启恢复」，逻辑上没有区分场景。

### 修复
- 新增内存集合 `touched`（不落盘）：装载过的曲目一律从 0 开始，并清掉落盘位置；
  只有「本会话从未装载过」才读落盘位置 → 续播只服务跨重启恢复。
- 新增 `switching` 标记：切歌窗口内禁止落盘位置 / seek 写盘，修掉派生 `pause` 的串写
  （替换 `audio.src` / `load()` 会异步派生 `pause`，此时 `current` 已指向新曲）。
- `loadCurrent(autoPlay, keepPosition)` 增加第二参数：仅 `setQuality` / `retry` 传 true
  （同曲重载沿用位置），切歌路径恒为 false。
- `playAt()` 同曲短路（比 `index` + `hash`）：点当前曲视为续播，不再 `resetProgress` 造成进度条归零闪烁。
- 顺手修增量基准 `lastPos`：`seek()`、`loadedmetadata` 落位、单曲循环重播三处都同步，
  否则会被 `addListenTime` 判成跳变（负增量）。
- 结尾语义：`saveCurrentResume` / `seek` 在 ≥ duration-3 或 <3 时清断点，避免重启停末尾或 0 秒。
- `removeAt` 移除当前曲时清该曲断点。

### 校验
`vue-tsc --noEmit`、`vite build` 均通过。
